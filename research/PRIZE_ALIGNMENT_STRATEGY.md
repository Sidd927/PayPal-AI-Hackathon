# Prize Alignment Strategy

Constraint: **one Grand or one Honorable** + **one Sponsor** per project.

| Target | Why we're competitive | What must be excellent |
|---|---|---|
| **Grand Prize (primary)** | Real, evidenced problem; deep PayPal Invoicing integration; AI that executes under control; uncrowded niche | End-to-end sandbox demo; polished UI; video |
| Best Use of PayPal + AI (fallback HM) | Every AI decision becomes a PayPal API call through a policy gate | Show request ids / state changes on screen |
| Most Impactful (fallback HM) | Small-business cash flow; owner wellbeing | Problem framing with sources |
| Best Use of Agentic Commerce (fallback HM) | Seller-side agent + payer-facing negotiation agent | Payer chat applying a plan live |
| **AG Grid (sponsor)** | Receivables board is a genuine data-grid problem: sorting by risk, filtering by reason, custom cell renderers, row selection for bulk diagnose, pinned totals | Use AG Grid features meaningfully, not as a plain table |
| Render (alt sponsor) | Hosted demo on Render via Blueprint | Only if the owner deploys |

We cannot win two sponsor prizes, so **AG Grid is the sponsor focus** (largest prize, strongest fit). Render is used because we need hosting anyway.
